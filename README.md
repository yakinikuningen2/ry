# 勝手に略すな。

好きな言葉から、意味不明だけど微妙にそれっぽい略語を生成する静的Webサイトです。HTML / CSS / JavaScriptで構成し、外部ライブラリ・外部API・AI・データベースは使用しません。

## 起動

Node.js 20以上を使用してください。依存パッケージのインストールは不要です。

```sh
npm run dev
```

ブラウザーで **http://localhost:3000** を開きます。終了は `Ctrl+C`。別ポートを使う場合、PowerShellでは `$env:PORT=3001; npm run dev` を実行します。

Windows PowerShellで「スクリプトの実行が無効」と表示された場合は、設定を変えずに `npm.cmd run dev` を使ってください。テスト・ビルドもそれぞれ `npm.cmd test`、`npm.cmd run build` で実行できます。

ES Modulesを使用するため、`index.html` のダブルクリックではなくHTTPサーバーで開いてください。開発用サーバーは自分のPCからのみ接続できます。本番環境で必要なのは静的ファイルの配信だけです。

## 使い方

- 1文字以上の言葉を入力し、「略す」またはEnterで生成します。入力文字数にアプリ側の上限はありません。日本語入力の変換確定中のEnterでは生成しません。
- 文字数は常におまかせです。12文字以内の入力は1〜6文字の範囲、それより長い入力は元の文字数の約12〜55%の範囲でランダムに生成します。元の言葉より必ず短くし、1文字の入力だけはそのまま表示して省略率0%にします。文字数の設定欄はありません。
- 「もう一度」は結果の元の言葉を使います。入力し直す必要はありません。
- コピーする内容は略語のみです。「Xで共有」は元の言葉・略語・ハッシュタグ・現在のページURLを入れたXの投稿画面を開きます。投稿確定はユーザーが行います。URLのクエリとフラグメントは共有しません。
- 「Discordで共有」は元の言葉・略語・ハッシュタグ・現在のページURLをまとめてコピーします。Discordの好きなチャンネルやDMに貼り付けて送信してください。URLのクエリとフラグメントは含めません。
- 履歴は保存しません。以前のバージョンで保存した履歴は、次回ページを開いたときにこのサイト専用のキーだけ削除します。

初期画面はサイト名・空の入力欄・「略す」ボタンを中央に表示します。履歴、例の単語ボタン、入力欄の例、初期サンプル結果、サブタイトル、入力上限の表示、補足説明は表示しません。生成後にだけ「今日からこれは〜と呼んでください。」の文面で結果を大きく見せ、X共有ボタンを表示します。余白は控えめにし、生成時の自動スクロールもありません。

スマートフォン向けには、画面幅に応じた余白と文字サイズ、2列×2行の操作ボタン、長い言葉の折り返し、入力文字サイズ16pxを設定しています。狭い画面では省略前後の統計も3列に収めます。実機での描画確認の制限は「検証」に記載しています。

## 生成ルールと文字数

空白・改行・ゼロ幅スペースを除いてから、`Intl.Segmenter`の書記素単位で文字数を数えます。例として、濁点が別コードポイントの「が」や家族の絵文字は各1文字です。古いブラウザーには、結合文字・絵文字の連結・国旗をまとめる簡易フォールバックがあります。

一文字ずつの抽出と、最大3文字の連続したまとまりの抽出をランダムに組み合わせます。小さい仮名と長音符は直前の文字に続けて選ばれやすくしますが、完全ランダムモードなので読みやすさは保証しません。選択後は元のインデックス順に並べ、元にない文字を追加しません。文字の連結でUnicodeの文字境界が変わるケースも再確認し、おまかせで選んだ文字数を保ちます。

同じ言葉の直前の結果を記憶し、ランダム抽出の再試行と確定的な代替候補で重複を避けます。同じ文字ばかりの入力などで別の結果が作れない場合は、その旨を表示します。省略率は `四捨五入((省略前−省略後) / 省略前 × 100)` です。

## Vercelで公開

1. このフォルダの内容をGitHubなどの新規リポジトリに保存します。
2. Vercelの「Add New → Project」からそのリポジトリをインポートします。
3. Framework Presetは **Other**。`vercel.json` によりBuild Commandは **npm run build**、Output Directoryは **dist** になります。
4. Deployを実行します。生成した`dist/`だけが公開され、テスト・開発用スクリプトは配信しません。

Vercel CLIを使う場合は、このフォルダで `npx vercel`（プレビュー）または `npx vercel --prod`（本番）を実行できます。Vercelへのログインとプロジェクト選択は自身で行ってください。公開はまだ実行していません。

ビルドはVercelの `VERCEL_PROJECT_PRODUCTION_URL`、なければ `VERCEL_URL` を使い、OGP画像・canonical・`og:url`を絶対URLにします。独自ドメインを明示したい場合や他の静的ホスティングを使う場合は、環境変数 `SITE_URL=https://example.com` を設定してビルドしてください。Vercelのシステム環境変数を無効にしている場合も`SITE_URL`を指定してください。Xの共有URLはビルド設定に依存せず、閲覧中のURLから生成します。

```sh
npm run build
```

参考：[Vercelのビルド設定](https://vercel.com/docs/builds/configure-a-build)、[システム環境変数](https://vercel.com/docs/environment-variables/system-environment-variables)。

## 検証

```sh
npm test
```

生成ルール・すべての指定文字数・元の文字順・Unicode・連続重複回避・異常入力・X共有URL・旧履歴の削除・入力を永続保存しないことを検証します。ブラウザーではさらに、Enter、コピー、共有リンク、画面幅を確認してください。

実装時の確認結果：22件の自動テストに合格し、101文字・4,097文字・10,000文字以上の入力、Unicode長文、長い人名での結果の長さと多様性、Discord共有文とコピー処理を検証しています。ローカルHTTP配信で200を確認、静的ビルド成功、OGP PNGを目視確認済みです。アプリ操作の自動テストはDOMアダプターを使い、クリップボードも代替実装で検証しています。Edgeでの実画面確認は操作ツールが現在のブラウザーURLを判別できず停止したため、スマートフォン幅での描画・実クリップボード・X投稿画面の表示は未検証です。XやDiscordへの実投稿はしていません。

## セキュリティとプライバシー

- 入力は端末内で処理します。外部通信、解析タグ、外部フォントはありません。
- 入力の文字列は`textContent`で表示し、HTMLとして挿入しません。
- 空文字・空白だけの入力を検証します。文字数の固定上限や入力欄の`maxlength`は設けません。
- 入力・生成結果は永続保存しません。localStorageには旧履歴の削除のためだけにアクセスし、アクセスが拒否されても生成できます。
- VercelではCSP、MIMEスニッフィング防止などのヘッダーを設定します。`connect-src 'none'`でスクリプトからの外部通信を制限します。
- X共有の操作時にのみ、選んだ元の言葉と略語がXに渡ります。ブラウザーの拡張機能など、サイト外の動作は対象外です。
- Discord共有ボタンは端末内で共有文をコピーします。Discordへの送信は、ユーザーがDiscordに貼り付けて投稿したときに行われます。

## ファイル

| ファイル | 用途 |
| --- | --- |
| `index.html` / `styles.css` | 日本語画面・レスポンシブデザイン・SEO設定 |
| `app.js` | 画面操作、コピー、共有 |
| `generator.js` | Unicode処理と略語生成 |
| `assets/` | favicon、1200×630 PNGのOGP画像 |
| `scripts/` | 開発用サーバー、静的ビルド、OGP画像生成 |
| `tests/` | Node.js標準テスト |
| `vercel.json` | Vercelのビルド・配信ヘッダー |

OGP画像は生成済みです。Windowsで変更する場合は `npm run ogp` を実行します（PowerShell / System.Drawing / Yu Gothic使用）。通常の起動や公開に画像の再生成は不要です。
